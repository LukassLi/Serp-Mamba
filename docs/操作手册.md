# Serp-Mamba 操作手册

## 一、项目目录结构

```
Serp_Mamba/
├── train.py                          # 训练入口
├── test.py                           # 纯推理入口（保存预测掩码 + 概率图）
├── evaluate.py                       # 独立测评入口（加载预测结果计算指标）
├── val_2D.py                         # 训练验证辅助函数（train.py 调用）
│
├── configs/                          # 数据集 YAML 配置
│   ├── drive.yaml                    # DRIVE 数据集
│   ├── fire.yaml                     # FIRE 数据集（仅推理，无标签）
│   ├── fundus.yaml                   # Fundus 数据集
│   ├── fives.yaml                    # FIVES 数据集
│   └── prime_fp20.yaml              # PRIME-FP20 数据集
│
├── evaluators/                       # 评测器框架
│   ├── __init__.py                   # 注册表：evaluator 名 → 类
│   ├── base.py                       # BaseEvaluator 基类
│   ├── default.py                    # 默认评测器（Dice/IoU/MCC/BM）
│   └── fives.py                      # FIVES 评测器（9 项指标）
│
├── dataloaders/                      # 数据加载
│   ├── dataset_registry.py           # ConfigDataSets（配置驱动）+ val_split_ratio
│   └── dataset.py                    # BaseDataSets（旧版）+ RandomGenerator 增强器
│
├── utils/                            # 工具函数
│   ├── metrics.py                    # 公共指标工具（所有指标函数集中于此）
│   ├── losses.py                     # 损失函数
│   ├── train_stats.py                # 训练统计与可视化
│   └── util.py                       # 通用工具
│
├── networks/                         # 网络工厂（旧版，当前未使用）
├── U_Mamba_main/                     # SerpMamba 模型定义
├── augmentations/                    # 数据增强
│
├── datasets/                         # 数据集存放目录
│   ├── DRIVE/
│   ├── FIRE/                         # (dataset_fire/)
│   ├── fundus_dataset/
│   ├── FIVES/
│   └── PRIME-FP20_DataPort/
│
└── experiments/                      # 训练输出（自动创建）
    └── <数据集名>/
        ├── *_best_model.pth
        ├── tf-logs/
        └── test_results/
            ├── predictions/          # 推理产出的预测掩码 PNG
            ├── probabilities/        # 推理产出的概率图 .npy
            └── output.txt            # 测评指标汇总
```

## 二、数据集概览

| 数据集 | 配置名 | 训练集 | 验证集 | 测试集 | 图像尺寸 | 评测器 | 说明 |
|--------|--------|--------|--------|--------|----------|--------|------|

## 三、训练

### 通用命令格式

```bash
python train.py --dataset <配置名> [可选参数]
```

### 各数据集训练命令

#### PRIME-FP20（默认数据集）

```bash
# 默认 16000 iterations
python train.py --dataset prime_fp20

# 自定义参数
python train.py --dataset prime_fp20 --max_iterations 20000 --base_lr 0.0001
```

#### DRIVE

```bash
# 默认 20000 iterations
python train.py --dataset drive
```

#### Fundus

```bash
# 默认 20000 iterations
python train.py --dataset fundus
```

#### FIVES

```bash
# 默认 960 iterations（= 2 epochs，480 train samples × batch_size 1）
python train.py --dataset fives

# 正式训练（约 40 epochs）
python train.py --dataset fives --max_iterations 20000

# 指定 GPU
CUDA_VISIBLE_DEVICES=0 python train.py --dataset fives --max_iterations 20000
```

> **FIVES 验证集说明**：FIVES 无官方验证集，配置中 `val_split_ratio: 0.2` 从 600 张训练图划出 120 张作为验证集（四病种均衡），剩余 480 张用于训练。

### 常用训练参数

| 参数 | 默认值 | 说明 |
|------|--------|------|
| `--dataset` | `prime_fp20` | 配置文件名（不含 .yaml）或 YAML 文件路径 |
| `--max_iterations` | 由配置决定 | 总训练迭代次数（覆盖配置中的值） |
| `--base_lr` | 0.0001 | 学习率 |
| `--num_classes` | 2 | 输出类别数 |
| `--patch_size` | 由配置决定 | 网络输入尺寸 |
| `--batch_size` | 1 | 批大小（**必须为 1**，Pixel_Executor 限制） |
| `--root_path` | 由配置决定 | 覆盖数据集根目录 |

### 训练输出

```
experiments/<数据集名>/
├── SerpMamba_best_model.pth         # 最佳模型（按 val Dice 选择）
├── model_iter_<iter>_dice_<score>.pth  # 最佳 checkpoint 副本
├── model_iter_<iter>.pth             # 每 2000 iter 的 checkpoint
├── train_stats.csv                   # 训练统计
└── tf-logs/                          # TensorBoard 日志
```

## 四、推理

推理只做模型前向传播，保存预测掩码和概率图，**不计算指标**。

### 基本命令

```bash
python test.py --dataset <配置名> --checkpoint_dir <模型目录>
```

### 各数据集推理命令

```bash
# PRIME-FP20
python test.py --dataset prime_fp20 --checkpoint_dir experiments/PRIME-FP20

# DRIVE
python test.py --dataset drive --checkpoint_dir experiments/DRIVE

# FIVES
python test.py --dataset fives --checkpoint_dir experiments/FIVES

# FIRE（无标签，仅保存预测）
python test.py --dataset fire --checkpoint_dir experiments/FIRE
```

### 常用推理参数

| 参数 | 说明 |
|------|------|
| `--dataset` | 配置文件名 |
| `--checkpoint_dir` | 模型 checkpoint 所在目录 |
| `--split` | 评估的数据划分（默认 `test`） |
| `--test_all` | 测试所有 .pth 文件（默认只测 `*_best_model.pth`） |
| `--save_dir` | 输出目录（默认 `checkpoint_dir/test_results`） |
| `--evaluate` | 推理完成后自动运行测评 |

### 推理输出

```
<save_dir>/
├── predictions/              # 预测掩码 PNG（白色=血管，黑色=背景）
│   ├── 1_A.png
│   └── ...
└── probabilities/            # softmax 概率图 .npy（供 AUC 等指标使用）
    ├── 1_A_prob.npy
    └── ...
```

## 五、测评

测评独立于推理，加载已保存的预测结果 + 标签 → 计算指标 → 写入 output.txt。

### 方式 1：推理后自动测评

```bash
python test.py --dataset fives --checkpoint_dir experiments/FIVES --evaluate
```

### 方式 2：独立运行测评（不需要重新推理）

```bash
python evaluate.py --dataset fives --pred_dir experiments/FIVES/test_results/predictions
```

### 测评参数

| 参数 | 说明 |
|------|------|
| `--dataset` | 配置文件名（用于确定标签路径和评测器类型） |
| `--pred_dir` | 预测掩码目录 |
| `--prob_dir` | 概率图目录（默认自动查找 `../probabilities/`） |
| `--split` | 标签所在划分（默认 `test`） |
| `--output` | 输出文件路径（默认 `pred_dir/../output.txt`） |

### 各数据集评测指标

| 评测器 | 指标列表 | 适用数据集 |
|--------|----------|-----------|
| `default` | Dice, IoU, MCC, BM | DRIVE, Fundus, PRIME-FP20 |
| `fives` | Dice, IoU, MCC, BM, SE, SP, PR, AUC, HD95 | FIVES |

## 六、新增数据集快速指南

### 步骤

1. **创建配置文件** `configs/<名称>.yaml`（参考现有配置）
2. **（可选）创建专属评测器** `evaluators/<名称>.py`（继承 `BaseEvaluator`，定义 `get_metric_names()`）
3. **（可选）在 `evaluators/__init__.py` 注册评测器**
4. **在配置中指定评测器** `evaluator: "<名称>"`

### 最简配置模板

```yaml
name: "新数据集"
description: "描述"
root_dir: "datasets/新数据集"
image_dir: "{split}/images"
label_dir: "{split}/labels"
split_map:
  train: "train"
  val: "val"
  test: "test"
image_ext: ".png"
label_name_transform:
  - change_ext: ".png"
image_mode: "RGB"
input_channels: 1
label_threshold: 0
label_rgb_mode: "mean"
patch_size: [512, 512]
batch_size: 1
max_iterations: 20000
base_lr: 0.0001
num_classes: 2
```

不加 `evaluator` 字段即自动使用 DefaultEvaluator（Dice/IoU/MCC/BM）。

如需从训练集划分验证集，添加：
```yaml
split_map:
  train: "train"
  val: "train"           # val 也读 train 目录
  test: "test"
val_split_ratio: 0.2     # 划出 20% 作为验证集
val_split_seed: 1337     # 固定种子，可复现
```
